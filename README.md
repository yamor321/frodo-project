# Frodo Project — שקיפות מחירים כפר סבא

פלטפורמה אזרחית להשוואת מחירי מוצרי צריכה בין רשתות, מול בנצ'מרק רשמי.
פיילוט: מוצרי חלב, רשתות עם סניף בכפר סבא. פרטי המקורות והארכיטקטורה:
[docs/sources.md](docs/sources.md).

## מצב נוכחי

שלב הוכחת היתכנות (בריף סעיף 6.4): פרסר יחיד לרשת פיילוט אחת — **שופרסל**.
`etl/normalize`, `etl/scoring`, `etl/benchmarks` ו-`site/` עדיין לא קיימים —
נבנים אחרי שהפרסר הראשון הוכח.

## הרצה מקומית

```bash
pip install -r requirements.txt
python -m unittest discover tests    # בדיקות יחידה, מול קובץ אמיתי שמור
python scripts/demo_shufersal.py     # הדגמה חיה מול הפורטל האמיתי
```

## מבנה תיקיות

```
etl/
  scrapers/shufersal.py   # רשימת קבצים, הורדה, פענוח XML (הרשת הראשונה)
data/
  raw/                     # תמונות מצב גולמיות (לא ב-git; ראו .gitignore)
  processed/               # טבלאות מנורמלות
  published/               # קלט לשכבת ההגשה הסטטית
tests/                     # בדיקות יחידה מול נתונים אמיתיים שמורים
scripts/                   # סקריפטי הדגמה/תפעול חד-פעמיים
docs/                      # מקורות מאומתים ותיעוד
```
